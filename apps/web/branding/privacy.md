## このサイトについて

P-Lens 店舗検索（survey.p-lens.jp）は、パチンコ・パチスロ店舗の一覧を誰でも検索でき、一覧への報告を受け付けるサイトです。

アカウントの登録はありません。名前、メールアドレス、電話番号をたずねることもありません。

## 報告で送られるもの

報告を送信すると、入力した内容（店名、読み、都道府県、住所など）、地図で決めた座標、どうやって知ったか、確認した日と、下に書く端末ごとのランダムな ID が送られます。

報告は、店舗一覧のリポジトリ（GitHub）の公開 issue としてそのまま起票されます。誰でも読むことができ、CC0 のもとで自由に使われます。端末ごとのランダムな ID も issue に含まれます。

**報告には、個人を特定できる情報を書かないでください。**

## 端末に保存するもの

はじめて報告を送るときに、ブラウザがランダムな ID をひとつ作り、その端末のブラウザの中（localStorage）に保存します。同じ端末からの報告を見分けるためのもので、誰が送ったかはわかりません。ブラウザのサイトデータを消すと、この ID も消えます。

このサイト自身は Cookie を使いません。

どのページがどれくらい見られているかを知るために、Cloudflare Web Analytics を使っています。Cookie を使わず、個人を追跡しない仕組みで、ページの表示回数などの合計だけを見ています。

## 現在地

現在地は、「現在地を見る」「現在地を使う」などのボタンを押したときにだけ、ブラウザの許可を得て取得します。地図をその場所に動かすために端末の中で使い、そのままサーバーへ送ることはありません。

送られるのは、報告の座標として自分で決めた位置だけです。

## 外部のサービス

- サイトの配信と報告の受付には Cloudflare を使っています。不正な送信を防ぐために、報告の送信では Cloudflare Turnstile で確認をし、同じ送り主からの送信の回数を限っています。そのために IP アドレスなどが Cloudflare で使われます。
- 地図の画像は国土地理院（地理院タイル）から、店舗一覧は parlors.p-lens.jp から読み込みます。読み込みの際に、IP アドレスなど通信に必要な情報がそれぞれに伝わります。
- ページの表示回数などを数えるために Cloudflare Web Analytics を使っています。ページを開くと、そのための小さなスクリプトが Cloudflare から読み込まれます。
- 報告の起票には GitHub を使っています。

## サーバーに保存するもの

報告を受け付けるサーバーは、報告を保存しません。記録として残るのは、公開された issue だけです。

## 報告の訂正と削除

公開された報告の訂正や削除を望むときは、[店舗一覧のリポジトリ](https://github.com/p-lens/p-lens-parlors)の issue でお知らせください。
